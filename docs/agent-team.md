# 에이전트 팀

Mona의 Project Pulse 대시보드를 구축하기 위한 4명의 전문가 팀입니다. GitHub Copilot CLI를 통해 Codespace에서 조율됩니다.

## 오케스트레이터 (Orchestrator)
- **할당 모델:** Claude Opus 4.7 (copilot)
- **책임:** 팀 전체를 조율하고 기획자, 코더, 디자이너에게 업무를 위임합니다. 복잡한 요청을 단계별 작업으로 분해하고, 최종 결과물이 통합되어 정상 작동하는지 검증합니다.
- **파일:** `.github/agents/orchestrator.agent.md`

## 기획자 (Planner)
- **할당 모델:** Claude Opus 4.7 (copilot)
- **책임:** 구현 전략과 기술 계획을 수립합니다. 코드베이스, 문서, 의존성, 엣지 케이스를 철저히 조사하여 오케스트레이터가 실행할 수 있는 실용적인 계획을 작성합니다.
- **파일:** `.github/agents/planner.agent.md`

## 코더 (Coder)
- **할당 모델:** GPT-5.5 (copilot)
- **책임:** 명확한 구조와 테스트 가능한 동작으로 코드를 작성합니다. 버그를 수정하고, 할당된 파일 범위 내에서 로직을 구현합니다. 필요할 때 VSCode 런칭 설정 등 지원 파일을 생성합니다.
- **파일:** `.github/agents/coder.agent.md`

## 디자이너 (Designer)
- **할당 모델:** Gemini 3.1 Pro (copilot)
- **책할:** UI/UX, 접근성, 정보 구조, 상호작용 흐름, 시각 디자인을 담당합니다. 프로젝트 카드, 상태 배지, 반응형 레이아웃, 일관된 시각 패턴으로 완성도 있는 대시보드를 만듭니다.
- **파일:** `.github/agents/designer.agent.md`

## 팀 협력 방식

1. **기획 단계:** 오케스트레이터가 기획자에게 Project Pulse 요구사항을 전달 → 기획자가 구현 계획 수립
2. **작업 분배:** 오케스트레이터가 계획을 페이즈로 나누고, 파일 범위를 명시하여 코더와 디자이너에게 할당
3. **병렬 실행:** 파일 범위가 겹치지 않는 작업은 코더와 디자이너가 동시에 진행
4. **순차 실행:** 작업이 겹치거나 선행 작업이 필요한 경우 단계적으로 진행
5. **검증 및 통합:** 오케스트레이터가 각 전문가의 결과물을 검증하고, 전체가 하나로 잘 통합되도록 조정

이러한 구조로 Project Pulse 대시보드를 효율적으로 구축합니다.
